# SmartSight Detection Framework

## AI-Powered Real-Time Object Detection & Visual Intelligence System

### Project Description
SmartSight Detection Framework is an AI-based object detection system developed using YOLOv8 and OpenCV. The system is capable of detecting multiple objects in images and videos with confidence scores and bounding boxes.

### Features
- Image Object Detection
- Video Object Detection
- Real-Time Detection Simulation
- Bounding Box Visualization
- Confidence Score Prediction
- Multiple Object Recognition

### Technologies Used
- Python
- YOLOv8
- OpenCV
- Google Colab
- NumPy

### Project Structure
SmartSight-Detection-Framework/
│
├── dataset/
├── models/
├── outputs/
├── screenshots/
├── videos/
├── requirements.txt
├── README.md
└── object_detection_system.ipynb

### How to Run
1. Install dependencies from requirements.txt
2. Open object_detection_system.ipynb in Google Colab
3. Run all cells
4. Upload image/video
5. View detection results
